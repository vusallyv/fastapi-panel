# Security policy

## Supported versions

Security fixes go into the latest release.

## Reporting a vulnerability

Please report it privately through [GitHub's advisory form](https://github.com/zaman-labs/fastapi-panel/security/advisories/new), not in a public issue.

Include what you found, how to reproduce it, and the impact you expect. You'll get a reply within a week, and we'll keep you updated until there's a fix. If you'd like credit, we'll name you in the advisory.

For how the panel protects itself and what's left to you, see the [security guide](docs/security.md).
